Archived content
================

This folder holds site sections that are no longer active but may be useful later.

- `content/robots/` contains the old robot MDX entries.
- `public/images/robots/` contains the images used by those old entries.
- `src/routes/robots-*` and `src/components/ui/RobotGallery.tsx` contain the old route modules and gallery component.

The active app intentionally does not import these files or generate `/robots` routes.
